- (decision) AD-1 Paradigme: Layered Pipeline — couches codec2→data→models→training→eval. Chaque couche ne dépend que de la précédente. Empêche le couplage circulaire entre phases expérimentales.
- (decision) AD-2 Codec2 comme représentation pivot figée — jamais de codec neuronal appris. Binds: tous les modèles. Prevents: dérive vers EnCodec/SoundStream qui annulerait l'hypothèse de recherche.
- (decision) AD-3 Mono-encodage 1200 bps 8 kHz — un seul mode Codec2, une seule fréquence. Prevents: fragmentation des pipelines si plusieurs modes coexistent.
- (decision) AD-4 CTC comme stratégie de décodage ASR — pas d'attention encoder-decoder. Prevents: explosion de complexité, permet greedy decode en inférence mobile.
- (decision) AD-5 Tokenizer caractères (49 classes) — pas de BPE/SentencePiece. Prevents: dépendance à un vocabulaire appris, simplifie le déploiement multilingue futur.
- (decision) AD-6 Dataset retourne (features, labels, lengths) — convention uniforme pour toutes les phases. Prevents: incompatibilité entre DataLoader et collate_fn.
- (decision) AD-7 Export TFLite comme format de livraison — pas ONNX en production. Binds: Phase 5+. Prevents: fragmentation des runtimes mobiles (SmsVox = TFLite).
- (constraint) Codec2 C library doit être installée sur la machine hôte — pas de wheel auto-suffisant.
- (constraint) CTC loss incompatible MPS — entraînement GPU = CUDA seulement (Kaggle T4).
- (version) PyTorch 2.2+, torchaudio 2.2+, Python 3.10-3.12, Codec2 1200bps, MFA french_mfa (IPA 45 phonèmes)
- (event) spine finalized — brownfield ratification, 7 ADs adopted from existing codebase
